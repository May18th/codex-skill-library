# 质量验收清单

选择与本次任务有关的项目；每项记录通过、失败或未验证及其证据，不能把“看起来正确”写成已测试。

| 产物 | 核心验收项 |
|---|---|
| 文案 | 对象与目的明确；有真实场景和细节；事实可追溯；无空话和逻辑冲突；术语与语气一致；没有编造经历 |
| 代码 | 满足需求与边界；基础与回归测试通过；异常路径覆盖；没有泄露密钥；涉及界面则检查桌面与移动端；未运行的测试明确标记 |
| 方案 | 问题与约束明确；步骤可执行；责任与资源清楚；风险与取舍公开；验收方式具体；无法确认的成本和时间标为估计 |
| 视觉 | 信息层级清晰；留白、配色、字体与控件一致；对比可读；关键状态可见；真实内容和双端尺寸下复核 |

比较“有无方法”的质量时，保持输入、任务难度和评价口径一致，保留两个输出及评分依据。没有对照和结果证据，不宣称显著提升。
