## 发布检查

- [ ] Skill 描述能区分触发场景与不适用场景。
- [ ] 步骤可执行，包含判断条件，而非只有原则口号。
- [ ] 关键方法能回溯到合法使用的来源，但 Skill 用原创表达。
- [ ] 未包含长篇原文、扫描全文或规避版权限制的材料。
- [ ] 用典型任务和反例完成行为检查；未验证的部分有明确标记。
- [ ] 未声称超出样本支持的准确率或领域权威性。
