# Codex 方法库

本目录保存经过实际任务验证的、可复用的方法记录。它不是 Skill 运行目录；可调用流程放在 `D:\Codex\skills\<skill-folder>\SKILL.md`。

## 目录

| 目录 | 用途 |
|---|---|
| `sources` | 书目、版本和来源核验记录；只保存必要的书目信息，不保存无权使用的全文 |
| `core-capabilities` | 需求沉淀、质量验收、审美参考和复盘记录 |
| `book-to-skill` | 新领域方法论提炼和 Skill 验证记录 |
